About Us

This website was created as part of the COS30045 unit to demonstrate web-based data visualization.

Project Purpose

The goal of this project is to provide an interactive way to explore energy consumption data for televisions sold in the Australian market. The data has been cleaned and processed using KNIME before being displayed on this website.

Data Source

The data comes from the Australian Government's Energy Rating website, which provides energy efficiency information for appliances.

Technology Used

  • HTML5 for structure
  • CSS3 for styling
  • JavaScript for interactivity
  • KNIME for data processing
  • GitHub Copilot for code assistance
